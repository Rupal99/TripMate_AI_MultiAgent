# TripMate_AI_MultiAgent
TripMate multi agent which helps in finding hotels, flights and planning the itinerary for the user

# How to run
 1. create the virtual env

```bash
python3 -m venv .venv
```
2. Activate the env

```
source .venv/bin/activate
```

3. Install the requirements

```
pip install -r requirements.txt
```
